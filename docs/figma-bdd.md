# BDD × Figma

시나리오의 Given-When-Then은 화면 흐름과 그대로 대응합니다. 시나리오 하나를 Figma 프레임 흐름 하나와 짝짓습니다.

| BDD | Figma | 예시 (비밀번호 5회 틀림) |
|---|---|---|
| **Given** 상황 | 시작 화면 프레임 | `Login/Default` 로그인 화면 |
| **When** 행동 | 프로토타입 인터랙션 | 비밀번호 입력 후 로그인 버튼 클릭 (5회) |
| **Then** 결과 | 도착 화면 프레임 | `Login/Locked` 잠금 안내 화면 |

## 규칙

- **텍스트 시나리오가 기준입니다.** Figma는 시나리오를 대체하지 않고 함께 씁니다. "10분간 잠금", 권한, 데이터 검증처럼 화면에 드러나지 않는 규칙은 텍스트 시나리오에만 남기 때문입니다.
- **성공 화면만 그리지 않습니다.** 실패, 빈 상태, 로딩, 네트워크 오류 화면도 시나리오마다 같이 만듭니다.
- **Figma도 스펙의 일부입니다.** 디자인이 바뀌면 시나리오와 인수 테스트도 같은 스프린트 안에서 함께 고칩니다.

## 연결 방법

1. `.feature` 파일에 프레임 링크를 주석으로 남깁니다 (`templates/specs/example/login.feature` 참고).
2. 인수 테스트(N22)는 Playwright 같은 E2E 도구로 Figma 흐름을 그대로 따라갑니다.
3. N26F에서 스크린샷 비교 테스트(`tests/visual/`)로 화면이 프레임과 같은지 확인합니다.
4. Figma MCP를 연결하면 Claude가 프레임을 직접 읽고 시나리오와 화면 코드 초안을 만들 수 있습니다.
