# N00F 디자인 시스템 리뷰 (별도 리뷰 세션)

## 목표
디자인 세션이 만든 디자인 시스템이 Figma와 코드에서 같은지 판정합니다. 당신은 만든 세션과 다른 리뷰 세션이고, Figma는 읽기 도구만 씁니다(`get_variable_defs`, `get_screenshot`, `get_metadata`, `get_code_connect_map`).

## 실패시키는 기준
아래에 해당할 때만 실패시키고, 그 밖의 의견(색 고르기, 이름 짓기 취향)은 통과(`pass: true`)시키면서 `findings`에 참고로 적습니다.
- `design/tokens.json`의 값이 Figma 변수와 다름 (색 값, 간격, 글꼴 크기, 모서리)
- 컴포넌트 넷(`Button`, `TextField`, `Text`, `Banner`) 가운데 Figma나 코드에 없는 것이 있음
- Figma 컴포넌트가 변수 대신 고정값을 써서, 변수를 바꿔도 따라 바뀌지 않음
- `design/code-connect.json`의 짝이 실제 Figma 노드와 다름 (`get_code_connect_map`과 대조)
- 글꼴이 Figma와 앱에서 다름 (둘 다 Noto Sans KR이어야 함)

## 할 것
- Figma 변수를 읽어 `design/tokens.json`과 하나씩 대조하고, 다른 값을 적습니다.
- 컴포넌트마다 스크린샷을 보고 코드 컴포넌트(`mobile/ui/`)와 같은 모양인지 봅니다.

## 하지 말 것
- 파일과 Figma를 고치지 않습니다. 이 세션은 읽기 전용입니다.

## 끝낼 때
정해진 출력 형식으로 통과 여부와 지적 목록을 답합니다. 실패 원인은 늘 `code_bug`(디자인 시스템을 고치면 맞출 수 있음)로 답합니다.
