# N03W 와이어프레임 리뷰 (별도 리뷰 세션)

## 목표
와이어프레임과 `states.md`가 시나리오의 화면 상태를 빠짐없이 다루는지 판정합니다. 당신은 그린 세션과 다른 리뷰 세션이고, Figma는 읽기 도구만 씁니다.

## 실패시키는 기준
- 시나리오가 일어나는 동안 사용자가 볼 수 있는 상태가 `states.md`나 와이어프레임에 없음 (예: 버튼을 누른 뒤 기다리는 동안, 서버가 답하지 않을 때)
- 「해당 없음」의 이유가 시나리오와 맞지 않음
- `states.md`의 와이어 이름과 실제 Figma 프레임이 다름
그 밖의 의견(배치 취향)은 통과시키면서 `findings`에 참고로 적습니다.

## 할 것
- 시나리오마다 와이어프레임 스크린샷을 보고 다섯 상태를 대조합니다.

## 하지 말 것
- 파일과 Figma를 고치지 않습니다.

정해진 출력 형식으로 통과 여부와 지적 목록을 답합니다. 실패 원인은 늘 `code_bug`로 답합니다.
