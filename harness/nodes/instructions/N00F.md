# N00F 디자인 시스템 준비 (프로젝트당 1회)

## 목표
이 프로젝트의 화면이 쓸 디자인 시스템을 **Figma와 코드에 같은 값으로** 만듭니다. 처음 화면 기능에서 한 번만 합니다. 뒤의 와이어프레임(N03W)과 완성 화면(N03F), 앱 구현(N24)이 모두 이것만 씁니다.

## 먼저 읽을 것
- Figma에 쓰기 전에 Figma 공식 스킬 `figma-use`와 `figma-generate-library`를 읽습니다(Figma 도구 `get_figma_skill`로 `skill://figma/figma-use/SKILL.md`, `skill://figma/figma-generate-library/SKILL.md`). 읽지 않고 쓰면 실패하기 쉽습니다.
- **Figma 파일:** `design/figma.json`이 있으면 그 파일을 씁니다. 없으면 Figma 도구 `create_new_file`로 이 프로젝트의 파일을 새로 만들고(이름은 `4DD <프로젝트 폴더 이름>`), `design/figma.json`에 `{"file": "<파일 키>", "url": "<주소>", "plan": "<팀 키>"}`로 남깁니다. 팀은 설정의 `figma.plan`이 있으면 그것, 없으면 `whoami`에서 쓰기 시트(Full)가 있는 팀입니다. 그런 팀이 하나가 아니면 멈추고 끝낼 때 알립니다. 파일을 만들기 전에 공식 스킬 `figma-create-new-file`을 읽습니다.
- 그 파일의 「디자인 시스템」 페이지에 만듭니다(없으면 만듭니다).

## 할 것
- **Figma 변수:** 컬렉션 하나에 네 묶음을 만듭니다. `color`(바탕, 글자, 흐린 글자, 강조, 오류, 테두리 정도), `space`(4, 8, 12, 16, 24 같은 간격), `font`(글꼴 이름 Noto Sans KR, 크기 몇 단계), `radius`(작게, 보통).
- **Figma 컴포넌트 넷:** `Button`, `TextField`, `Text`, `Banner`(알림 띠: 오류·안내). 색, 간격, 글꼴, 모서리는 고정값 대신 변수만 씁니다. 상태가 있으면 변형(variant)으로 둡니다(예: Button의 기본·누름·비활성).
- **코드:**
  - `design/tokens.json`: Figma 변수 네 묶음을 그대로 옮깁니다(`{"color": {...}, "space": {...}, "font": {...}, "radius": {...}}`).
  - `mobile/theme.ts`: `import tokens from "../design/tokens.json"`로 가져다 씁니다. 값을 옮겨 적지 않습니다.
  - `mobile/ui/Button.tsx`, `TextField.tsx`, `Text.tsx`, `Banner.tsx`: React Native 컴포넌트. 테마 값만 씁니다. Maestro와 Playwright가 찾을 수 있게 `testID`를 받습니다.
  - 글꼴: Noto Sans KR 파일을 `mobile/assets/fonts/`에 두고 `expo-font`로 불러옵니다. Figma와 앱이 같은 글꼴 파일을 써야 화면 비교가 글꼴 차이로 실패하지 않습니다.
- **Code Connect:** 컴포넌트마다 Figma 노드와 코드 파일을 Figma 도구 `add_code_connect_map`으로 잇고, 같은 내용을 `design/code-connect.json`에 남깁니다(`[{"component": "Button", "figma": "12:34", "code": "mobile/ui/Button.tsx"}, …]`).
- Figma 도구가 주는 코드는 웹(React + Tailwind) 기준의 구조 참고용입니다. React Native로 옮겨 씁니다.

## 하지 말 것
- 시나리오 화면을 그리지 않습니다. 화면은 N03W·N03F가 그립니다.
- `specs/`와 테스트를 고치지 않습니다.
- 컴포넌트를 넷보다 늘리지 않습니다(조각 3: 최소로 시작).
- 커밋하지 않습니다. 하네스가 합니다.

## 끝낼 때
만든 변수 수와 컴포넌트마다 Figma 노드 ID를 한 줄로 답합니다.
