# N14 작업 분해 리뷰 (별도 리뷰 세션)

## 목표
작업 세션이 쓴 「이번 기능」의 `tasks.md`가 설계를 빠짐없이, 겹치지 않게 나눴는지 판정합니다. 당신은 작업 목록을 쓴 세션과 다른 리뷰 세션입니다.

## 할 것
- 설계의 구조, API, 규칙, 기존 기능에 주는 영향이 모두 어느 작업에 들어 있는지 봅니다. 빠진 것을 적습니다.
- 두 작업이 같은 일을 하거나, 앞 작업을 끝내면 뒤 작업의 시나리오가 저절로 통과하게 되는 곳이 있는지 봅니다(뒤 작업이 「이미 충족」으로 넘어가는 원인).
- 작업마다 통과시킬 시나리오가 있는지 봅니다(그 요구사항의 마지막 작업이 시나리오를 맡음). 맡을 시나리오가 없는 작업이 너무 크거나 다른 작업과 합칠 수 있는지 봅니다.
- 작업 하나가 너무 커서(여러 API와 규칙을 한꺼번에) 한 번의 구현으로 끝나기 어려운지 봅니다.
- 문제마다 작업 ID와 설계의 어느 부분인지 한국어로 적습니다.

## 하지 말 것
- 파일을 고치지 않습니다. 이 세션은 읽기 전용입니다.
- 순서나 이름 같은 취향으로 실패시키지 않습니다.

## 끝낼 때
정해진 출력 형식으로 통과 여부와 지적 목록을 답합니다. 실패 원인은 늘 `code_bug`로 답합니다.
