# 요구사항 스펙: 로그인 (N02)

## 목적
가입한 사용자가 아이디와 비밀번호로 안전하게 로그인할 수 있게 한다.

## 요구사항
- R1 아이디와 비밀번호가 맞으면 로그인에 성공하고, 틀리면 실패한다.
- R2 같은 아이디로 비밀번호를 5번 연속 틀리면 그 아이디를 10분 동안 잠근다. 로그인에 성공하면 연속 실패 수는 0으로 돌아간다.
- R3 잠긴 아이디로 로그인하면, 비밀번호가 맞더라도 거절하고 잠금이 풀리기까지 남은 시간을 알려 준다.

## 범위 밖
- 회원 가입, 비밀번호 재설정, 소셜 로그인
- 로그인 화면 (백엔드만 다룬다)

## 제약
- 비밀번호는 평문으로 저장하지 않는다.
- 잠금 시간은 서버 시계로 계산한다.
